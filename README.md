# 🚀 NETASSET — ISP Asset Management Frontend

## 📌 About This Project

NETASSET is a frontend-focused ISP Asset Management System designed around realistic infrastructure-management workflows.

Instead of a simple landing page or generic CRUD demo, this project presents a multi-module administrative interface for managing physical assets, network resources, virtual resources, topology, locations, customers, users, providers, lifecycle/status information, reports, and system configuration.

The project focuses on **frontend implementation, UI/UX, responsive design, interaction patterns, data presentation, forms, tables, and navigation** using vanilla HTML, CSS, and JavaScript.

### Current Scope

This repository is specifically the **frontend version of NETASSET**.

- ✅ Frontend interface completed
- ✅ Multi-page admin application
- ✅ Interactive frontend workflows
- ✅ Responsive UI structure
- ✅ GitHub Pages deployment
- ❌ Backend / database is not included in this repository

A separate NETASSET repository is reserved for the future full-stack implementation.

## 🎨 Design System

NETASSET uses an enterprise-oriented network-management visual style inspired by infrastructure and asset-management applications.

Key design principles include:

- Clear information hierarchy
- Dense but readable tables
- Technical identifiers and metadata
- Consistent status indicators
- Search and filter controls
- Detail-oriented asset views
- Predictable administrative workflows
- Consistent sidebar navigation
- Reusable cards, badges, buttons, forms, and modal patterns
- Responsive page layouts
